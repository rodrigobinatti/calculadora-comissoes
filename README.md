# Calculadora de Comissões

Calculadora de uso privado para acompanhamento de vendas e remuneração variável.

## Funcionalidades
- Dashboard com indicadores e gráficos.
- Cadastro individual de vendas.
- Pesquisa de modelos e anos dos veículos.
- Comissão básica de 0,5% sobre vendas.
- Metas e campanhas configuráveis.
- Premiações acumulativas.
- Calendário de trabalho e estimativa de DSR.

## Como utilizar
Abra o arquivo index.html em um navegador compatível.

## Privacidade
Mantenha o repositório privado. Não publique informações corporativas sem autorização.

## Atenção
Os cálculos são estimativas e devem ser conferidos com as regras oficiais de remuneração.
