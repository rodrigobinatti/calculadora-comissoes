# Calculadora de Comissões — uso privado

Site estático e responsivo, sem servidor ou banco de dados. Abra `index.html` no navegador para começar.

## Funcionalidades
- Dashboard com vendas, faturamento, remuneração estimada e gráfico.
- Cadastro individual de vendas, modelo e ano; modelo manual quando não constar da lista.
- Comissão fixa de 0,5%, valor fixo por carro, garantias e despachante (R$ 55 cada).
- Meta individual de 7 carros; alavanca de 10%, 20%, 30% nos patamares de 100%, 120%, 130% da loja, conforme orientação fornecida.
- Campanhas acumulativas editáveis por data, categoria, quantidade mínima, período de contagem, prêmio e opção todos/excedentes.
- Calendário de folgas e domingos com histórico de escalas, marcações manuais e DSR **estimado**.
- Backup/exportação e importação de dados JSON.

## Privacidade e GitHub
Crie um repositório **Private** no GitHub e envie `index.html` e `README.md`. Não publique pelo GitHub Pages: Pages não é controle de acesso para material interno. Para usar no computador, abra `index.html` localmente. Para usar no celular, baixe o arquivo ou utilize um ambiente de hospedagem privada com autenticação aprovada pela empresa.

Os registros ficam no armazenamento local do navegador, **não** no GitHub. Não há sincronização entre dispositivos. Exporte backups frequentemente e guarde-os em local autorizado.

## Ressalvas de cálculo
A tabela oficial do PDF possui faixas de alavanca diferentes das regras ditadas na conversa. A versão segue as regras fornecidas pelo usuário; confirme com RH antes de usar para apuração real. O DSR é uma **estimativa** calculada como base variável x dias de repouso / dias de trabalho. Marque folgas e feriados reais; o calendário não importa feriados automaticamente. As regras específicas de campanhas podem exigir validação manual. O valor de campanha é calculado sobre vendas elegíveis dentro da vigência, mesmo quando o mínimo é contado no mês inteiro.
